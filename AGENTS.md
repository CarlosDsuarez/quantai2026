# AGENTS.md

## Cursor Cloud specific instructions

Python quant-research pipeline (Fase 1: ingesta). Dependencies are declared in
`requirements.txt` and installed into a project virtualenv at `.venv/` by the
startup update script. **Always activate it first:** `source .venv/bin/activate`.
There is no lockfile, no test suite, and no lint config in this repo.

### Services / scripts (all are one-shot CLI scripts, not long-running servers)

| Script | Command | Needs | Notes |
|---|---|---|---|
| Price fetcher | `python src/ingestion/price_fetcher.py` | network (Yahoo Finance) | Core functional entrypoint. Downloads 3y OHLCV for the 30 tickers in `config/universe.csv` → `data/raw/prices/{ticker}.csv`. Exit code ≠ 0 if any ticker fails. |
| Coverage report | `python src/validation/coverage_report.py` | reads `data/raw/articles/*.parquet` | Runs even with zero articles (reports 0% coverage). Depends on scraper output. |
| Bloomberg scraper | `python src/ingestion/bloomberg_scraper.py --url-list <csv>` | Playwright chromium + manual Bloomberg cookies | See caveats below. Cannot run unattended. |
| LLM sentiment extractor | imported as a module (`src/extraction/llm_sentiment_gap_extractor.py`) | `ANTHROPIC_API_KEY` | Deferred client init: the module imports without the key; the key is only required when a sentiment call actually runs. Fase 2 integration. |

### Non-obvious caveats

- **`config/bloomberg_cookies.json` and `.env` are gitignored and NOT present.**
  The scraper reads cookies exported manually from an authenticated
  bloomberg.com session; it never logs in or evades bot/CAPTCHA challenges. It
  also needs a hand-curated URL-list CSV (`--url-list`). Without both it exits
  early by design — this is not an environment failure.
- **The scraper launches a VISIBLE (non-headless) chromium by default** so a
  human can solve anti-bot challenges. In a headless VM it needs a display
  (e.g. the Desktop pane / Xvfb) or the `--headless` flag. It also calls
  `input()` to pause for manual challenge solving, so it requires an
  interactive TTY. The Playwright chromium browser binary is installed by the
  update script; a plain `pip install` does NOT fetch it.
- **`price_fetcher.py` overwrites the window to the last 3 years ending today**,
  so the date range shifts each run — this is expected.
- Outputs (`data/raw/`, `data/processed/`, `outputs/`) are gitignored and
  regenerated by the scripts.
